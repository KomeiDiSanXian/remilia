## 🐛 高优先级 Bug 修复

### 1. ✅ DLQ Enqueue 双重 Panic 风险

**问题描述**: 在 `infra/dlq/dlq.go:158-160` 中，`defer recover()` 无法捕获 `select` 内部的 channel send panic。

**原因分析**:
```go
defer func() {
    if r := recover(); r != nil {
        // 这个 recover 只能捕获 defer 后面的语句panic
        // 无法捕获下面 select 里的 panic
    }
}()

select {
case dlq.queue <- item:  // 如果 channel 已关闭，这里会 panic
    return
}
```

**修复方案**: 移除冗余的 defer recover，因为已经有 `queueClosed.Load()` 检查。

**状态**: ✅ 已验证 - 当前代码已正确实现，不需要额外修复

### 2. ⚠️ 自适应限流器的信号量泄漏风险

**问题描述**: 在 `middleware/adaptive.go:151-170` 中，如果 `next(ctx)` panic，信号量不会被释放。

**原因分析**:
```go
case arl.sema <- struct{}{}:
    arl.currentLoad.Add(1)
    start := time.Now()
    
    defer func() {
        <-arl.sema  // 如果上面 panic，这里可能不会执行
        arl.currentLoad.Add(-1)
        // ...
    }()
    
    return next(ctx)  // 如果这里 panic，defer 会执行，但 return 值会丢失
```

**修复方案**: 在 defer 中添加 recover。

**状态**: ⚠️ 待修复

### 3. ⚠️ Matcher 删除竞态条件

**问题描述**: 在 `core/engine/process.go:133-156` 中，临时 matcher 的删除逻辑存在竞态条件。

**原因分析**:
```go
m.rt.mu.Lock()
if atomic.LoadInt32(&m.rt.isTemp) == 1 && ... {
    m.rt.useCount++
    if m.rt.useCount >= m.rt.maxUseCount {
        m.rt.deleted = true
        m.rt.mu.Unlock()  // ⚠️ 在这里解锁，但后面还要访问 m.rt.isTemp
        
        // ⚠️ 问题：另一个 goroutine 可能在这里修改 m.rt.isTemp
        if atomic.LoadInt32(&m.rt.isTemp) == 1 {
            engine.services.tempManager.Remove(m)
        } else {
            select {
            case engine.services.pendingDeleteCh <- m:
            default:
                // ...
            }
        }
        return
    }
}
m.rt.mu.Unlock()
```

**修复方案**: 在解锁前保存 `isTemp` 状态。

**状态**: ⚠️ 待修复

**文件**: `middleware/adaptive.go`

**修改**:
```go
// Middleware 返回中间件函数
func (arl *AdaptiveRateLimiter) Middleware() eventctx.Middleware {
    return func(next eventctx.Handler) eventctx.Handler {
        return func(ctx *eventctx.Context) error {
            arl.totalRequests.Add(1)

            // 尝试获取令牌
            select {
            case arl.sema <- struct{}{}:
                // 获取成功
                arl.currentLoad.Add(1)
                start := time.Now()

                defer func() {
                    // 确保一定释放令牌
                    <-arl.sema
                    arl.currentLoad.Add(-1)

                    // 记录延迟
                    latency := time.Since(start)
                    arl.latencySum.Add(latency.Nanoseconds())
                    arl.latencyCount.Add(1)
                }()

                // ✅ 修复：捕获 panic，确保 defer 能执行
                var err error
                func() {
                    defer func() {
                        if r := recover(); r != nil {
                            err = fmt.Errorf("panic in handler: %v", r)
                            logger.WithField("panic", r).Error("[AdaptiveRateLimiter] Handler panic recovered")
                        }
                    }()
                    err = next(ctx)
                }()
                
                return err

            default:
                // 超过限制，拒绝请求
                arl.rejectedRequests.Add(1)

                logger.WithFields(logger.Fields{
                    "current_limit": arl.maxConcurrency.Load(),
                    "current_load":  arl.currentLoad.Load(),
                    "rejected":      arl.rejectedRequests.Load(),
                }).Warn("[AdaptiveRateLimiter] Request rejected")

                return fmt.Errorf("adaptive rate limit exceeded (limit: %d)", arl.maxConcurrency.Load())
            }
        }
    }
}
```

### 修复 4: 错误处理 - adjustLoop

**文件**: `middleware/adaptive.go`

**修改**:
```go
func (arl *AdaptiveRateLimiter) adjustLoop() {
    defer arl.wg.Done()

    ticker := time.NewTicker(arl.config.AdjustInterval)
    defer ticker.Stop()

    lastAdjustTime := time.Now()

    for {
        select {
        case <-arl.ctx.Done():
            return

        case <-ticker.C:
            // 冷却期检查
            if time.Since(lastAdjustTime) < arl.config.CooldownPeriod {
                continue
            }

            // 获取当前指标
            cpu := arl.getCPUUsage()
            memory := arl.getMemoryUsage()
            latency := arl.getLatencyP99()
            currentLimit := arl.maxConcurrency.Load()

            // ✅ 修复：采集失败时跳过调整
            if cpu < 0 || memory < 0 {
                logger.Warn("[AdaptiveRateLimiter] Metrics collection failed, skipping adjustment")
                continue
            }

            // 决策是否调整
            newLimit := arl.decideLimit(cpu, memory, latency, currentLimit)

            if newLimit != currentLimit {
                arl.adjustLimit(newLimit)
                lastAdjustTime = time.Now()

                logger.WithFields(logger.Fields{
                    "old_limit":      currentLimit,
                    "new_limit":      newLimit,
                    "cpu":            fmt.Sprintf("%.2f%%", cpu*100),
                    "memory":         fmt.Sprintf("%.2f%%", memory*100),
                    "latency_p99":    latency,
                    "target_cpu":     fmt.Sprintf("%.2f%%", arl.config.TargetCPU*100),
                    "target_latency": arl.config.TargetLatency,
                }).Info("[AdaptiveRateLimiter] Limit adjusted")
            }
        }
    }
}
```
