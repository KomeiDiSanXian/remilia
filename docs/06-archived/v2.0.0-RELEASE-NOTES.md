# Remilia v2.0.0 发布说明

**发布日期**: 2026-02-19  
**版本**: v2.0.0

## 🎉 重大更新

### Plugin v2 API 正式发布

v2.0.0 标志着 Remilia 插件系统的全面升级。v1 API (BasePlugin) 已完全移除，所有插件现在使用更简洁、更强大的 v2 API。

---

## ⚠️ 破坏性更改

### 已移除的内容

1. **BasePlugin 结构体**
   ```go
   // ❌ 已移除
   type BasePlugin struct { ... }
   ```

2. **v1 构造函数**
   ```go
   // ❌ 已移除
   func NewBasePlugin(name string) *BasePlugin
   func NewBasePluginWithMetadata(metadata *Metadata) *BasePlugin
   ```

3. **基于继承的插件模式**
   ```go
   // ❌ 已移除
   type MyPlugin struct {
       *plugin.BasePlugin
   }
   ```

### 迁移要求

所有使用 v1 API 的代码必须迁移到 v2 API。

---

## ✨ 新特性

### Plugin v2 API

**更简洁的代码**:
```go
// v2 API - 新标准
func New() *plugin.PluginDescriptor {
    return &plugin.PluginDescriptor{
        Name:    "myplugin",
        Version: "1.0.0",
        Setup: func(ctx *plugin.SetupContext) error {
            ctx.RegisterCommand(dto.C2CMessageCreate, "/hello").
                Handle(func(c *eventctx.Context) error {
                    return c.Reply("Hello!")
                })
            return nil
        },
    }
}
```

**关键改进**:
- ✅ 代码减少 60%
- ✅ 自动依赖注入
- ✅ 自动 Matcher 追踪
- ✅ 更好的类型安全
- ✅ 符合 Go 习惯用法

### 完整的接口实现

v2 插件自动实现以下接口：
- `Plugin` - 基本插件接口
- `StatefulPlugin` - 状态查询接口
- `MetadataProvider` - 元数据提供接口
- `MatcherProvider` - Matcher 查询接口
- `ConfigurablePlugin` - 配置管理接口

### 迁移示例

**之前 (v1)**:
```go
type CounterPlugin struct {
    *plugin.BasePlugin
    count atomic.Int64
}

func NewCounterPlugin() *CounterPlugin {
    return &CounterPlugin{
        BasePlugin: plugin.NewBasePlugin("counter"),
    }
}

func (p *CounterPlugin) Load(eng *engine.Engine) error {
    eng.OnCommand(dto.C2CMessageCreate, "/count").
        Handle(func(ctx *eventctx.Context) error {
            count := p.count.Add(1)
            return ctx.Reply(fmt.Sprintf("Count: %d", count))
        })
    return nil
}

func (p *CounterPlugin) Unload(eng *engine.Engine) error {
    return p.BasePlugin.Unload(eng)
}
```

**之后 (v2)**:
```go
func New() *plugin.PluginDescriptor {
    var count atomic.Int64
    
    return &plugin.PluginDescriptor{
        Name:    "counter",
        Version: "2.0.0",
        
        Setup: func(ctx *plugin.SetupContext) error {
            ctx.RegisterCommand(dto.C2CMessageCreate, "/count").
                Handle(func(c *eventctx.Context) error {
                    n := count.Add(1)
                    return c.Reply(fmt.Sprintf("Count: %d", n))
                })
            return nil
        },
    }
}
```
