│
├── fun/               # 娱乐互动插件 (P2-P3) 🟢
│   ├── random/        │ - 随机工具
│   ├── game/          │ - 文字游戏
│   ├── joke/          │ - 笑话段子
│   └── fortune/       │ - 运势占卜
│

│

│   ├── github/        │ - GitHub 集成
│   ├── ai/            │ - AI 对话
│   ├── image/         │ - 图片处理
