# v2.0.0 最终发布总结

## 概述

v2.0.0 是 Remilia 框架的重大版本，完成了架构简化和问题修复。这是一个**非破坏性的简化版本** - 全局 Engine 已移除，但 API 更加友好。

---

## 核心变更

### 1. 简化 Bot 创建 ✅

**变更**: `New()` 现在自动创建 Engine，无需手动传递。

**之前 (v1.x)**:
```go
// ❌ 使用全局 Engine（已移除）
bot := remilia.New(info)

// ✅ 需要手动创建和传递
engine := remilia.NewEngine()
bot := remilia.New(info, remilia.WithEngine(engine))
```

**现在 (v2.0)**:
```go
// ✅ 自动创建独立 Engine
bot := remilia.New(info)

// ✅ 或使用自定义 Engine
customEngine := remilia.NewEngine()
bot := remilia.New(info, remilia.WithEngine(customEngine))
```

**优势**:
- 🎯 更简单：零配置即可使用
- 🔒 更安全：每个 Bot 独立 Engine
- 🧪 测试友好：自动隔离

---

### 2. 移除全局 Engine ✅

**已移除的 API**:
```go
// ❌ 已移除
remilia.GetDefaultEngine()
remilia.GetGlobalEngine()
remilia.ResetDefaultEngine()
remilia.NewWithEngine()  // 不再需要
```

**影响**: 无 - `New()` 已自动处理

---

### 3. 修复 Prometheus 计数器 Panic ✅

**问题**: Counter 不能减少，但代码尝试减少导致 panic

**修复**:
```go
// 之前：可能导致 panic
mc.poolGets.Add(float64(stats.Gets) - float64(lastGets))

// 现在：只添加正数
if stats.Gets >= lastGets {
    mc.poolGets.Add(float64(stats.Gets - lastGets))
}
```

**文件**: `metrics.go`

---

### 4. 修复测试失败 ✅

#### 4.1 TestContextOverRelease

**问题**: 期望 refs 为负数，但实际为 0

**原因**: `released` 标志阻止了重复 release

**修复**: 更新测试期望值
```go
// 修复前
assert.Less(t, refs, int32(0))

// 修复后
assert.Equal(t, int32(0), refs)
```

#### 4.2 TestDeadLetterQueue_Shutdown

**问题**: 5 个项目只处理了 3 个

**修复**: 增加 worker 数量和超时时间
```go
// 修复前
Workers: 1,
timeout: 5*time.Second

// 修复后
Workers: 3,
timeout: 10*time.Second
```

---

### 5. 更新 Example 文件 ✅

修复了 3 个 example 文件中的 `GetGlobalEngine()` 调用：

- ✅ `example/context_integration/main.go` - 7 处
- ✅ `example/webhook/run_with_plugins/main.go` - 1 处
- ✅ `example/webhook/config_based/main.go` - 1 处

**修复方式**:
```go
// 之前
engine := remilia.GetGlobalEngine()

// 现在
engine := remilia.NewEngine()
```

## 向后兼容性

### ✅ 完全兼容（更简单）

**旧代码**:
```go
// v1.x - 需要 ResetDefaultEngine
func TestFeature(t *testing.T) {
    defer remilia.ResetDefaultEngine()
    bot := remilia.New(info)
}
```

**新代码（更简单）**:
```go
// v2.0 - 自动隔离
func TestFeature(t *testing.T) {
    bot := remilia.New(info)
    // 无需清理
}
```

### 不兼容的代码

仅影响直接使用已删除 API 的代码：

```go
// ❌ 这些代码无法编译
engine := remilia.GetDefaultEngine()
remilia.ResetDefaultEngine()

// ✅ 简单替换
engine := remilia.NewEngine()
// ResetDefaultEngine() 不再需要
```
