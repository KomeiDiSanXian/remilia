# v2.0.0 全局 Engine 移除总结

## 概述

v2.0.0 版本完成了架构重构的最后一步：**彻底移除全局 Engine**。这是一个破坏性变更，但极大提升了框架的设计质量和可维护性。

## 变更内容

### 已移除

| API | 说明 |
|-----|------|
| `var defaultEngine` | 全局 Engine 变量 |
| `GetDefaultEngine()` | 获取全局 Engine |
| `GetGlobalEngine()` | 获取全局 Engine（已废弃） |
| `ResetDefaultEngine()` | 重置全局 Engine |

### 已修改

| API | 变更 |
|-----|------|
| `New(info, ...options)` | 现在**必须**提供 `WithEngine()` 选项 |

### 新增

| API | 说明 |
|-----|------|
| `NewWithEngine(info, ...options)` | 推荐的创建方式，自动创建独立 Engine |

## 代码变更统计

| 文件 | 变更类型 | 说明 |
|------|---------|------|
| `engine.go` | 删除 | 移除全局 Engine 和相关函数 (60+ 行) |
| `bot.go` | 修改 | New() 添加 panic 检查 |
| `engine_default_test.go` | 删除 | 删除整个文件（测试全局 Engine） |
| `engine_test.go` | 修改 | 移除 TestGetGlobalEngine |
| `bot_test.go` | 修改 | 所有测试添加 WithEngine (10 处) |
| `bot_graceful_shutdown_test.go` | 修改 | 所有测试添加 WithEngine (6 处) |
| `bot_shutdown_test.go` | 修改 | 添加 WithEngine (1 处) |
| `bot_engine_isolation_test.go` | 修改 | 更新测试逻辑 (2 处) |
| `engine_auto_cleaner_test.go` | 修改 | 移除 ResetDefaultEngine (8 处) |
| `metrics_pool_test.go` | 修改 | 移除 ResetDefaultEngine (2 处) |

### 总计

- **删除**: ~80 行（全局 Engine 相关代码）
- **修改**: ~30 处（测试和示例）
- **新增文档**: 1 个完整迁移指南

## 影响分析

### 破坏性变更

**编译错误**:
```go
// ❌ 这些代码会报错
engine := remilia.GetDefaultEngine()
// -> undefined: GetDefaultEngine

defer remilia.ResetDefaultEngine()
// -> undefined: ResetDefaultEngine

bot := remilia.New(info)
// -> panic: Engine is required
```

### 必须的代码修改

所有使用 Remilia 的代码都需要更新：

1. **应用代码**: 改用 `NewWithEngine()`
2. **测试代码**: 移除 `ResetDefaultEngine()`
3. **示例代码**: 更新所有示例

## 优势

### 1. 架构更清晰

**之前**:
```go
// ❌ 隐式全局依赖
bot := remilia.New(info)
// Engine 从哪来？不清楚！
```

**现在**:
```go
// ✅ 显式依赖
bot := remilia.NewWithEngine(info)
// 每个 Bot 都有自己的 Engine
```

### 2. 测试更简单

**之前**:
```go
// ❌ 需要手动重置
func TestFeature1(t *testing.T) {
    defer remilia.ResetDefaultEngine()
    // ...
}

func TestFeature2(t *testing.T) {
    defer remilia.ResetDefaultEngine()
    // ...
}
```

**现在**:
```go
// ✅ 自动隔离
func TestFeature1(t *testing.T) {
    bot := remilia.NewWithEngine(info)
    // ...
}

func TestFeature2(t *testing.T) {
    bot := remilia.NewWithEngine(info)
    // ...
}
```

### 3. 多实例支持

**之前**:
```go
// ❌ 共享全局 Engine，相互干扰
bot1 := remilia.New(info1)
bot2 := remilia.New(info2)
```

**现在**:
```go
// ✅ 完全独立
bot1 := remilia.NewWithEngine(info1)
bot2 := remilia.NewWithEngine(info2)
```

### 4. 内存更可控

**之前**:
- 全局 Engine 永远不会释放
- 即使 Bot 停止，Engine 仍在内存中

**现在**:
- Engine 随 Bot 创建和销毁
- 内存自动回收

### 5. 并发更安全

**之前**:
- 全局 Engine 需要加锁保护
- 多个 Bot 竞争全局锁

**现在**:
- 每个 Engine 独立锁
- 无全局锁竞争

## 迁移工具

### 自动化脚本

```bash
#!/bin/bash
# migrate-to-v2.sh

echo "Migrating to Remilia v2.0.0..."

# 1. 替换 New() 为 NewWithEngine()
find . -name "*.go" -type f -exec sed -i \
  's/remilia\.New(/remilia.NewWithEngine(/g' {} +

# 2. 删除 ResetDefaultEngine 调用
find . -name "*.go" -type f -exec sed -i \
  '/remilia\.ResetDefaultEngine()/d' {} +

# 3. 删除 defer ResetDefaultEngine
find . -name "*.go" -type f -exec sed -i \
  '/defer remilia\.ResetDefaultEngine()/d' {} +

# 4. 格式化代码
go fmt ./...

echo "Migration complete! Running tests..."
go test ./...
```
