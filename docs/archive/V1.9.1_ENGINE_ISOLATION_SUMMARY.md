# v1.9.1 改进总结 - Engine 隔离

## 概述

v1.9.1 版本解决了 Remilia 框架的一个重要架构问题：**全局 Engine 的测试隔离问题**。通过提供新的 API 和详细的文档，推动用户从全局 Engine 迁移到独立 Engine 实例。

## 实现的特性

### Engine 隔离支持

**优先级**: 中等

**问题描述**:

早期版本使用全局 Engine 单例，导致：
- 测试间相互干扰，难以隔离
- 无法运行多个独立 Bot 实例
- 全局状态管理复杂

**解决方案**:

#### 1. 新增 NewWithEngine() 便捷构造函数

```go
// ✅ 推荐：自动创建独立 Engine
bot := remilia.NewWithEngine(info)

// 等价于
engine := remilia.NewEngine()
bot := remilia.New(info, remilia.WithEngine(engine))
```

**特性**:
- 自动创建独立 Engine
- 简洁易用的 API
- 与现有代码完全兼容
- 支持传入自定义 Engine

**实现**: `bot.go`

---

#### 2. 标记全局 Engine 为 Deprecated

更新了以下函数的文档：

**GetDefaultEngine()**:
```go
// Deprecated: 推荐使用 NewEngine() 创建独立实例
func GetDefaultEngine() *Engine
```

**New()**:
```go
// ⚠️  注意：此函数默认使用全局 Engine，不推荐用于生产环境
func New(info *dto.BotInfo, options ...BotOption) *Bot
```

添加了详细的警告和推荐做法，引导用户迁移。

**实现**: `engine.go`, `bot.go`

## 使用示例

### 迁移前（不推荐）

```go
// ❌ 使用全局 Engine
bot := remilia.New(info)

// ❌ 测试需要手动重置
func TestFeature(t *testing.T) {
    defer remilia.ResetDefaultEngine()
    engine := remilia.GetDefaultEngine()
    // ...
}
```

### 迁移后（推荐）

```go
// ✅ 使用独立 Engine
bot := remilia.NewWithEngine(info)

// ✅ 测试自动隔离
func TestFeature(t *testing.T) {
    bot := remilia.NewWithEngine(testInfo)
    engine := bot.GetEngine()
    // ...无需清理
}
```

## 最佳实践总结

### ✅ 推荐

1. **默认使用 NewWithEngine()**
   ```go
   bot := remilia.NewWithEngine(info)
   ```

2. **测试中独立 Engine**
   ```go
   func TestFeature(t *testing.T) {
       bot := remilia.NewWithEngine(testInfo)
       // 无需清理
   }
   ```

3. **配置与创建分离**
   ```go
   engine := remilia.NewEngine()
   configureEngine(engine)
   bot := remilia.New(info, remilia.WithEngine(engine))
   ```

### ❌ 避免

1. 使用全局 Engine: `bot := remilia.New(info)`
2. 手动重置: `defer remilia.ResetDefaultEngine()`
3. 获取全局实例: `engine := remilia.GetDefaultEngine()`
