# Metrics Monitoring Example

性能监控示例

## 特性

- ✅ 请求计数统计
- ✅ 延迟跟踪(最小/最大/平均)
- ✅ 成功率监控
- ✅ 系统资源监控
- ✅ 慢请求检测
- ✅ 定期报告

## 快速开始

```bash
cp config.example.yaml config.yaml
go run main.go
```

## 命令

- `/ping` - 快速响应测试
- `/slow` - 慢速响应测试
- `/stats` - 查看性能统计
- `/health` - 系统健康检查

## 监控指标

### 请求指标
- 总请求数
- 成功/失败数
- 成功率

### 延迟指标
- 平均延迟
- 最小延迟
- 最大延迟

### 系统指标
- Goroutines数量
- 内存使用
- GC次数

## 最佳实践

1. **定期报告**: 每30秒输出一次统计
2. **资源监控**: 每10秒检查系统资源
3. **慢请求**: 记录超过1秒的请求
4. **异常检测**: 监控goroutine和内存异常
