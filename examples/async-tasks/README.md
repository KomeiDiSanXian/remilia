# Async Tasks Example

异步任务处理示例

## 特性

- ✅ 异步任务创建
- ✅ 任务状态跟踪
- ✅ 进度更新
- ✅ 任务列表管理
- ✅ 线程安全
- ✅ 长时间任务处理

## 快速开始

```bash
cp config.example.yaml config.yaml
go run main.go
```

## 命令

- `/start` - 启动异步任务
- `/status <task_id>` - 查询任务状态
- `/list` - 列出所有任务

## 使用流程

1. 用户发送 `/start` 创建任务
2. Bot立即返回任务ID
3. 任务在后台异步执行
4. 用户可随时查询进度
5. 任务完成后可查看结果

## 适用场景

- 数据分析
- 报告生成
- 批量处理
- 文件转换
- 长时间计算

## 设计要点

1. **立即响应**: 不阻塞用户
2. **状态管理**: 跟踪任务状态
3. **线程安全**: 使用互斥锁
4. **进度反馈**: 分步骤更新
5. **可取消**: 支持Context取消
